# AMD Polaris / gfx803 / RX580 — AVX2, KoboldCPP, ZLUDA и ComfyUI для Windows

Закреплённый набор ZLUDA/HIP для **AMD Polaris / gfx803 / RX580**.
Замеры получены на RX580 2048SP с 8 ГБ видеопамяти. Компоненты: ComfyUI,
KoboldCPP, PyTorch, ONNX Runtime DirectML, OpenVINO CPU.

## Моя оптимизированная сборка KoboldCPP

[KoboldCpp AVX2 / Vulkan / NUMA](https://github.com/aktalascloud/koboldcpp-avx2-vulkan-numa) — отдельный репозиторий автора:
оптимизация для Haswell с AVX2, PGO/LTO, настройка Vulkan для RX580,
а также дополнительные возможности HybridMoE и Windows NUMA.
У проекта собственные релизы и замеры CPU/Vulkan.
Эти результаты нельзя складывать с процентами ZLUDA из таблицы ниже:
это разные эксперименты и сборки.

Для поиска: AMD Polaris (Поларис), gfx803, Radeon RX580 / РХ580,
AVX2, KoboldCPP (Коболд), ZLUDA (Злуда), ComfyUI (КомфиУИ), HIP / ROCm,
CUDA 11.8, DirectML, OpenVINO. AVX2 — набор инструкций исходного CPU и одно
из направлений оптимизации связанного форка; отдельный прирост от AVX2
в этом репозитории не измерялся.

## Медиапайплайн без ComfyUI

Мой [KoboldCpp media pipeline](https://github.com/aktalascloud/koboldcpp-media-pipeline) —
отдельный Windows-пайплайн для изображений и музыки на базе оптимизированной
сборки KoboldCpp CPU/Vulkan. Он добавляет автоматическое переключение моделей,
обработку лиц, восстановление всего изображения и необязательное увеличение
разрешения через Helaman ATD 4×. Предусмотрены интерфейсы, совместимые с A1111
и OpenAI; интеграция с OpenWebUI описана в его документации.

Это отдельный вариант работы с медиа помимо ComfyUI, **а не компонент данного
установщика**. Используйте инструкции, релизы и условия лицензий моделей из
того репозитория. Необязательные веса GPEN имеют ограничение Non-Commercial;
лицензия кода не распространяет свои разрешения на эти веса. Поддержка видео
отложена. Замеры медиапайплайна не смешиваются с результатами ZLUDA ниже.

## Какие результаты есть

Прежние замеры от 2026-10-22: Windows 11, RX580 2048SP, Xeon E5-2696 v3,
32 ГБ ОЗУ, драйвер 31.0.14037.18001. Драйвер не менялся. Новых генераций и
замеров производительности GPU ради публикации не выполнялось.

Контрольная генерация: **128 токенов, 8,46 ток/с при декодировании**;
декодирование — 15,13 с, весь запрос — 17,07 с, обработка промпта — 8,77 ток/с.

| Запрос | CPU, с | RX580, с | Прирост пропускной способности запроса | Снижение задержки |
|---|---:|---:|---:|---:|
| Арифметика | 5,734 | 5,266 | +8,89% | 8,16% |
| Перевод | 7,875 | 5,109 | +54,14% | 35,12% |
| Длинный контекст | 53,125 | 50,610 | +4,97% | 4,73% |
| Развёрнутый ответ | 11,563 | 11,343 | +1,94% | 1,90% |

Это **одиночные парные замеры времени выполнения полного запроса**,
а не измерение ускорения от каждого патча:
одна модель Qwen3-4B IQ4_XS, 8 потоков, контекст 1024, CPU без GPU-слоёв против
24/37 слоёв на Radeon. BLAS batch отключён в обоих случаях. Учтены обработка
промпта, кэш и накладные расходы; одновременно могли идти подготовка и компиляция.
Повторов и изолированного бенчмарка нет. Формула прироста:
`(время_CPU / время_GPU - 1) × 100%`; снижение задержки:
`(1 - время_GPU / время_CPU) × 100%`.

Четыре ответа дословно совпали. В арифметическом запросе обе версии ошиблись
одинаково: на `17 × 23` ответили `401`. Совпадение проверяет воспроизводимость,
а не истинность ответа. Отдельные простые контрольные запросы дали правильные
ответы: `4`, `63`, `Paris`. Сырые логи, промпты и локальные конфигурации
не публикуются. Доступны только [числовая таблица](data/paired-latency.csv)
и [количество токенов и скорости](data/decode.csv).

**Нет замеров прироста от отдельных патчей, сравнения с Vulkan или скорости
генерации изображений в ComfyUI.** ComfyUI была установлена, но не запускалась.

## Установка из релиза

1. Скачать установочный ZIP из [Releases](https://github.com/aktalascloud/polaris-gfx803-rx580-avx2-koboldcpp-zluda-comfyui-windows/releases).
2. Распаковать в доступную для записи папку с коротким путём.
3. Прочитать [лицензии и первоисточники](THIRD_PARTY_NOTICES.md).
4. Запустить `Install.cmd` и использовать профиль AMD Polaris / gfx803.
5. После установки пользоваться файлами запуска внутри созданной папки `runtime`.

Это **небольшой онлайн-установщик**, а не публикация личного офлайн-архива.
Он скачивает нужные закреплённые версии у издателей. Нужны Windows x64, интернет,
совместимый уже установленный GPU-драйвер, около 20 ГБ места на время установки
и [Microsoft VC++ Runtime x64](https://aka.ms/vs/17/release/vc_redist.x64.exe).
При отсутствии VC++ установка остановится с официальной ссылкой.

```powershell
.\Install.cmd -Backend AMD -AcceptThirdPartyLicenses
# Необязательный источник HIP 5.7.1: SDK копируется, системная установка не изменяется.
.\Install.cmd -Backend AMD -HipRoot "C:\Program Files\AMD\ROCm\5.7" -AcceptThirdPartyLicenses
```

AMD Setup не запускается: MSI-пакеты SDK распаковываются в административном
режиме `/a`; пакеты видеодрайвера не устанавливаются. Распаковка может потребовать
дополнительных локальных прав. В существующую папку установка не выполняется.
После прерывания сохраните и проверьте неполную установку, затем выберите свободный путь.
Установщик не меняет драйвер, реестр GPU, TDR, BIOS и настройки защиты.

Публичный установщик не проходил повторную полную проверку, в том числе на GPU.
Для загрузки выбран
официальный Python 3.12.10, тогда как исходные замеры получены на 3.12.14.
В обоих случаях используется ABI `cp312` для пакетов wheel, но это отличие
инструкции по установке, а не дополнительный замер. Совместимость с другими
картами и драйверами не гарантируется.

## Запуски после установки

- `Start-ComfyUI.cmd`: UI на `127.0.0.1:8188`, FP32/lowvram, VAE на CPU.
- `Start-Kobold.cmd`: UI на `127.0.0.1:5021`; есть `-ModelPath` и `-GpuLayers`.
- `Python-CUDA.cmd script.py`: PyTorch 2.2.1+cu118.
- `Python-ONNX.cmd script.py`: DirectML через ONNX Runtime и OpenVINO CPU.

Модели **не включены** ни в Git, ни в релиз. После отдельного подтверждения
`Download-Model.cmd` скачает исходную контрольную модель GGUF прямо с
[Hugging Face](https://huggingface.co/mradermacher/Qwen3-4B-Instruct-2507-heretic-uncens-i1-GGUF)
и сверит SHA256. Ключи и данные учётных записей не запрашиваются и не сохраняются.
Другую модель GGUF с подходящей лицензией можно самостоятельно скачать в `runtime/models`.

Для ComfyUI нужна отдельная совместимая SD1.x/SDXL-модель с подходящей лицензией:
положите её в `runtime/apps/ComfyUI/models/checkpoints`. Закреплённая ревизия
ComfyUI от 2025-08-31 **не поддерживает Z-Image**. Автообновления и менеджер нод
не включены. Подключение папки ZIMAGE не добавляет поддержку архитектуры.

## Патчи и ограничения

Полный перечень: [docs/PATCHES.md](docs/PATCHES.md).
Критическое исправление KoboldCPP — `--blasbatchsize -1`, с `nommq` и сохранёнными
24 слоями на GPU. Обычный BLAS batch давал неверный текст; сравнивать скорость
правильного и неправильного вычисления как «ускорение патча» нельзя.

На AMD используются rocBLAS с поддержкой gfx803, ZLUDA 3.9.5 и три DLL ZLUDA,
установленные под именами CUDA-библиотек Torch. cuDNN/TF32 и неподдерживаемые
реализации attention отключены. Для очень малых
batched GEMM нет Tensile-решения. OpenVINO GPU на Ellesmere возвращал нули:
используется только CPU. DirectML здесь не означает установленный `torch-directml`.
