**RX580 · gfx803 · Windows x64** — ZLUDA, HIP/ROCm, DirectML и OpenVINO с опциональным ComfyUI.

## Установка

Распакуйте ZIP в короткий доступный для записи ASCII-путь, например `C:\AI\Polaris-Setup`, и запустите **Install.cmd**. Прочитайте условия компонентов и выберите ComfyUI (`Y` или Enter — да).

Установка со всеми опциями:

```powershell
.\Install.cmd -InstallRoot C:\AI\Polaris-New -WithComfyUI -WithTorchDirectML -WithSmallGemmPatch
```

Нужны Windows x64, интернет, около 20 ГиБ свободного места и уже установленный совместимый драйвер AMD. Установщик сам скачивает зависимости, применяет согласованные библиотеки gfx803 и ставит VC++ x64, если он отсутствует. Для выбранного ComfyUI создаётся ярлык на рабочем столе. Существующая папка назначения не перезаписывается; драйвер не меняется. Модели скачиваются отдельно с [Hugging Face](https://huggingface.co/models) с учётом их лицензий.

| Запускатель в установленной папке | Назначение |
|---|---|
| `Python-CUDA.cmd` | Torch 2.2.1+cu118 через ZLUDA 3.9.5 / HIP 5.7.1 |
| `Python-ONNX.cmd` | ONNX DirectML 1.24.4 и OpenVINO 2026.4.1; провайдер выбирается в вашем коде |
| `Python-DirectML.cmd` | Опциональный отдельный Torch DirectML; доступно устройство `dml_device` |
| `Start-ComfyUI.cmd` | Локальный интерфейс/API `127.0.0.1:8188`; FP32, low VRAM, VAE на CPU |
| `Check-Zluda.cmd` | Ручная проверка CUDA/PTX без Torch и моделей |
| `Run-ZLUDA.cmd`, `HIP-Shell.cmd` | Запуск совместимых приложений и оболочка с локальными путями HIP |

CUDA/DirectML-запускатели поддерживают `-c`, `-m` и пути к скриптам. В профиле ComfyUI внешние API-ноды отключены; облачные ключи не настраиваются.

## Патчи и результаты

По умолчанию ставится согласованная пара **rocBLAS + gfx803 kernels от advanced-lvl-up**, подмены DLL для Torch и сохранённый оригинальный NVRTC. Это не означает, что весь HIP SDK или исходники ZLUDA переписаны. Неудачные варианты optic/vega автоматически не устанавливаются.

**Small-GEMM включается отдельно:** `-WithSmallGemmPatch` исправляет маленькие FP32 GEMM с размерами 1–8 на проверенном Polaris device 0. Исходный backend проходит **63/69 случаев strided**; патч — **69/69 в каждом из четырёх API**, максимальная ошибка — `3,34e-6`. Проверены ordinals и откат. Это исправление корректности, а не обещание ускорения генерации.

На контрольной RX580 прошли Torch DirectML FP32/FP16, строгий ONNX DirectML, OpenVINO CPU и сложение векторов через CUDA. Новая установка проверена с существующим SDK. **Запуск и генерация ComfyUI не проверены.** OpenVINO GPU/Ellesmere возвращал неверные нули — используйте CPU.
