# Polaris / gfx803 / RX580: ZLUDA, HIP/ROCm, DirectML и OpenVINO для Windows

Универсальный набор локальных AI-бэкендов с опциональным ComfyUI-Zluda.
[English](README.md) · [Список патчей](docs/PATCHES.md) · [Лицензии](THIRD_PARTY_NOTICES.md)

## Установка

1. Скачайте ZIP из [Releases](https://github.com/aktalascloud/polaris-gfx803-rx580-zluda-rocm-hip-comfyui-windows/releases/tag/v0.3.0), распакуйте, например, в `C:\AI\Polaris-Setup`.
2. Запустите **Install.cmd**. Выберите установку ComfyUI (Enter — да) и подтвердите условия сторонних компонентов.
3. Установщик автоматически скачает ZLUDA, HIP SDK, патченный rocBLAS с подходящими gfx803 blobs и все закреплённые Python-зависимости. Если отсутствует Microsoft VC++ x64 Runtime, установит официальный пакет с проверкой подписи. Windows может запросить права администратора.
4. Для ComfyUI автоматически применит патч запуска, установит зависимости и создаст ярлык **ComfyUI - Polaris ZLUDA** на рабочем столе.

Нужны Windows x64, интернет, около 20 ГиБ свободного места во время установки и **уже установленный совместимый драйвер AMD с amdhip64.dll**. Драйвер, TDR, реестр и BIOS установщик не меняет. Генерацию и тесты не запускает.

По умолчанию установка идёт в `runtime` рядом с Install.cmd. Существующую папку назначения установщик не перезаписывает. После сбоя может остаться неполная папка: при повторной попытке выберите новую.

```powershell
.\Install.cmd -WithComfyUI -AcceptThirdPartyLicenses
.\Install.cmd -WithoutComfyUI -AcceptThirdPartyLicenses
# Дополнительно: -InstallRoot C:\AI\Polaris-Runtime -HipRoot "C:\Program Files\AMD\ROCm\5.7" -NoDesktopShortcut
```

Параметр `-AcceptThirdPartyLicenses` используйте после прочтения условий производителей.

В установленной папке доступны:

- `Python-CUDA.cmd script.py` — PyTorch 2.2.1+cu118 через ZLUDA, с локальными DLL и настройками совместимости.
- `Python-ONNX.cmd script.py` — отдельное окружение DirectML / OpenVINO. В своём коде выбирайте `DmlExecutionProvider` для DirectML и `CPU` для OpenVINO.
- `Run-ZLUDA.cmd program.exe [аргументы]` — запуск другого совместимого CUDA-приложения. Конкретному приложению могут понадобиться собственные зависимости и подмены DLL; совместимость со всеми CUDA-программами не обещается.
- `HIP-Shell.cmd` — командная строка с локальными путями HIP.
- `Start-ComfyUI.cmd` и ярлык, если выбран ComfyUI — интерфейс и локальный API `http://127.0.0.1:8188`; FP32, low VRAM, VAE на CPU. Внешние API-ноды отключены; облачные ключи не нужны и не настраиваются.

Модели скачиваются отдельно с [Hugging Face](https://huggingface.co/models) с учётом лицензии и формата приложения. В релизе моделей нет.

## Опциональное исправление GEMM, PyTorch DirectML и диагностика

В релизе v0.3.0 добавлены флаги **`-WithSmallGemmPatch`** и **`-WithTorchDirectML`**, оба выключены
по умолчанию. Small-GEMM исправляет маленькие FP32 GEMM с размерами 1–8 на
проверенном Polaris device 0. Остальные операции передаются исходному backend.
Это не полный перенос ROCm и не обещание ускорения генерации.

PyTorch DirectML ставится отдельно: Python 3.11.9, Torch 2.4.1+cpu и
`torch-directml 0.2.5.dev240914`. Суффикс `+cpu` относится к ядру Torch;
физическую Radeon предоставляет DirectML. CUDA Torch и ONNX не смешиваются.
`Check-Zluda.cmd` проверяет CUDA Driver API и PTX/vector_add без Torch и моделей.
Выбор физической Radeon и индексы DXGI/Torch DirectML обнаруживаются отдельно.

[Установка, сборка, откат, ограничения и результаты](docs/SMALL-GEMM.md).
Полный установщик повторно проверен в чистой папке с существующим HIP SDK;
генерация и запуск ComfyUI не выполнялись. Прежние ограничения v0.2.1 ниже
относятся к старому релизу, в котором этого опционального исправления ещё не было.

## Что уже пропатчено

**После успешной установки** набор содержит рабочий rocBLAS от advanced-lvl-up с соответствующими gfx803 blobs, ZLUDA 3.9.5, подмены DLL для Torch и настройки локальной загрузки. Вручную копировать blobs не нужно.

Сам HIP SDK 5.7.1 берётся оригинальный: установщик заменяет в своей копии только rocBLAS и каталог ядер. ZLUDA — закреплённая сборка upstream. Утверждать, что весь ROCm/HIP или исходники ZLUDA дополнительно пропатчены, неверно.

Рабочие blobs — [advanced-lvl-up v1.0.0](https://github.com/advanced-lvl-up/Rx470-Vega10-Rx580-gfx803-gfx900-fix-AMD-GPU/releases/tag/v1.0.0). Ранее варианты likelovewant v0.5.7 были отклонены. Повторная проверка ниже показала: optic проходит часть сценариев, но остаётся нестабильным и исключён из автоматической установки. Патчи Schaka относятся к Linux и в Windows DLL не применялись. Ускорение каждого blob отдельно не измерялось.

В репозитории уже есть исходный патч ComfyUI, логика автоматических подмен и [точные URL/SHA256](profiles/components.json). Релиз — небольшой **онлайн-установщик**: необходимые бинарники автоматически скачиваются у авторов. У автора патченного rocBLAS не указана явная лицензия проекта; в архиве исходников также нет отдельной лицензии. Поэтому сомнительный по правам бинарный репак здесь не публикуется.

## Повторная проверка blobs: 23 октября 2026

[Методика, результаты и решения по патчам](docs/BLOB-RETRY-2026-10-23.md) · [Численные данные](data/blob-retry-2026-10-23.json).

- Рабочая пара advanced-lvl-up прошла оба запуска по восемь FP32/FP16-проверок.
- Полный **optic** один раз прошёл проверки, но повторно упал перед FP16. В генерации с 24 GPU-слоями: **8,10 токена/с** против **8,25** у рабочего набора, то есть **-1,78%**.
- На четырёх FP32-матрицах размеров, характерных для диффузии, изменение производительности optic: **-54,19%, -66,11%, -66,46%, -0,05%**. Это GEMM, а не замеры изображений/с в ComfyUI.
- Полный vega-fallback упал. Все четыре частичные подмены DLL/ядер дали падения или неверные результаты. В установщик они не добавлены.
- Vulkan из той же старой сборки при 24 слоях: **9,58 токена/с** без BLAS batching; **9,25 токена/с** с batch 512, но с более быстрой обработкой промпта. ZLUDA с optic и batch 512 упала до контрольных запросов.
- Твоя отдельная оптимизированная конфигурация Vulkan: **33,09 токена/с** против **8,25** у ZLUDA, примерно **4,01 раза**. Здесь также отличаются версия, число GPU-слоёв, CPU-потоки и ядра: это сравнение конфигураций, а не эффект одного патча. Для оптимизированного Vulkan сделаны два запроса по 128 токенов; для ZLUDA с 24 слоями — три.

**В установщике сохранена рабочая пара advanced-lvl-up.** Неудачные blobs и смешанные комплекты автоматически не устанавливаются. Рабочие файлы и защищённые файлы драйвера не изменились. На момент выпуска v0.2.1 полная установка и генерация ComfyUI не проверялись; новая проверка установщика с существующим SDK отдельно описана выше. Генерация ComfyUI остаётся непроверенной. Скрипт GPU-проверки запускается только вручную; Install.cmd тесты не выполняет.

## Что проверялось раньше

Замеры от 22 октября 2026: RX580 2048SP, Polaris/gfx803, 8 ГиБ, Windows 11, драйвер 31.0.14037.18001. Ранее прошли FP32/FP16 GEMM, небольшая свёрточная сеть, 60 BMM/copy итераций, LayerNorm/Softmax, DirectML на физической Radeon без CPU fallback и OpenVINO CPU. Некоторые маленькие batched GEMM не поддерживаются. OpenVINO GPU/Ellesmere возвращал неверные нули — используйте CPU.

ComfyUI был установлен, но **генерация не проверена**. Закреплён старый commit `c0c011dca91b595091a4b032770da366fc90fb2b`, без поддержки Z-Image. 23 октября 2026 по отдельному запросу выполнены новые изолированные GEMM-тесты и генерации языковой модели; результаты приведены в отчёте повторной проверки. Установщик v0.2.1 тогда проверялся статически. Для опционального дополнения теперь отдельно выполнена новая установка с существующим SDK, описанная выше. В рецепте Python 3.12.10, в исходном окружении был 3.12.14; ABI колёс одинаковый — cp312.

Здесь нет универсальных обещаний токенов/с, изображений/с или процентов ускорения отдельных патчей. Лаунчеры языкового приложения и загрузчик его модели не входят в набор. Языковое приложение в отчёте используется только как стенд для замеров.
